# v4 concept review

Eleven final concept screens, generated with the built-in image generation tool. Open index.html to browse them at full size. The game source and build were not changed during this concept pass.

The strongest visual anchors are 04-loadout (operator design), 05-shift (gameplay materials and Warden), and 06-locker (tension and close-up framing).

08-core was regenerated after review: the first pass did not clearly depict three concentric walkways. The selected version separates all three, retains four switches, and clearly marks the retracting outer segment. The first pass is retained under alternates/08-core-first-pass.png.

## Reference chain

01-title establishes the style. 02-mic, 03-sectors, 04-loadout, and 05-shift use that title as their visual reference. 06-locker, 07-crew, and the first Core use 05-shift and 04-loadout. 09-results, 10-paywall, and 11-overseer use 05-shift and 03-sectors. The final Core is a targeted edit of its first pass.

The prompts in PROMPTS.md specify the shared direction and each screen. Reference instructions ask the generator to retain palette, painted materials, character identities, and typography while replacing the composition and labels for each screen.

## Core refinement prompt

Targeted revision of the Core concept: preserve the exact painterly petrol/ivory industrial style, palette, operator design, two Warden robots, interface text and amber practical lighting. Correct the arena topology to exactly THREE clearly separated concentric circular pedestrian walkways around the central machine, all visible in the same top-down isometric view. Pull the camera higher and farther back and narrow the central spindle so the innermost walkway remains visible. Outer ring large, middle medium, inner small, same floor height, dark void gaps and short radial bridges. Four kill-switch consoles, two amber and two red; operator on front middle ring; Wardens on different rings; retracting outer segment. Preserve CORE 2/4, PURGE 0:42, OVERSEER subtitle, joystick and RUN.

These are visual design references, not production-ready 3D assets. Small painted markings and fine geometry still need deliberate reconstruction if implemented. The concept counters and proposed modes preserve the reference set; they do not describe the current game's exact feature set.
